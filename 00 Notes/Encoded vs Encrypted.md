**Encoded vs Encrypted** — they sound similar, but they serve very different purposes:

### 🔹 Encoding

* **Purpose:** Make data readable/usable by different systems
* **Security:** ❌ Not secure
* **Reversible:** ✅ Easily (no key needed)
* **Examples:**

  * Base64 (used in emails, images in HTML)
  * ASCII / Unicode

👉 Think: *“formatting data so computers understand it”*

---

### 🔹 Encryption

* **Purpose:** Protect data from unauthorized access
* **Security:** ✅ Secure (uses keys)
* **Reversible:** ✅ Only with the correct key
* **Examples:**

  * AES (used in secure apps, files)
  * RSA (used in HTTPS, digital signatures)

👉 Think: *“locking data so only authorized people can read it”*

---

### 🔑 Simple analogy

* **Encoding** = writing a message in Morse code → anyone who knows Morse can read it
* **Encryption** = putting the message in a locked box → only someone with the key can open it
